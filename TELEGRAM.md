# Запуск Илюха Дроп в Telegram

URL приложения: https://ilyuha-drop-vpn.frostyocean71.chatgpt.site

1. Откройте официального @BotFather: https://t.me/BotFather
2. Отправьте /newbot. Укажите имя «Илюха Дроп» и свободный username, заканчивающийся на bot.
3. Сохраните выданный токен в менеджере паролей. Для запуска этой версии токен не нужен: не вставляйте его в сайт или исходники.
4. В /mybots выберите бота → Bot Settings → Configure Mini App → Enable Mini App. Укажите URL приложения выше. Названия пунктов могут зависеть от интерфейса BotFather.
5. Для кнопки в меню чата: /setmenubutton → выберите бота → URL выше → название «Играть».
6. Откройте профиль бота, нажмите Launch app / «Открыть приложение». Прямая ссылка после настройки: https://t.me/ВАШ_USERNAME?startapp

Проверка на телефоне: приложение открывается без входа ChatGPT; изображения помещаются; ежедневный бонус доступен; кейс списывает VPN один раз; предмет появляется в инвентаре; кнопка Telegram «Назад» возвращает к кейсам; после повторного открытия на том же устройстве прогресс остаётся.

## Границы первого прототипа

Это работающая клиентская демоверсия для Telegram. Баланс и предметы хранятся в localStorage устройства, не синхронизируются между устройствами и не защищены от изменения пользователем. Telegram initDataUnsafe не используется для авторизации. Персональные данные Telegram не отправляются на сервер. Для общего аккаунта и защищённой экономики следующим этапом нужны backend, проверка подписи initData, база данных и серверная выдача результатов. СБЭУ и Апгрейд остаются макетами.

Для настройки Main Mini App не требуется постоянно запущенный процесс бота. Автоответ на /start и inline-кнопки можно добавить позднее отдельным сервером.
